# Abhay Tiwari — Engineering Portfolio

A responsive, static portfolio website built with HTML, CSS and a small amount of JavaScript. It is designed for GitHub Pages and does not require a framework, build process or paid hosting.

## Preview locally
1. Extract this ZIP.
2. Open the `abhay-portfolio` folder.
3. Double-click `index.html` to open it in a browser.

For a more reliable local preview, use VS Code with the Live Server extension and choose **Open with Live Server**.

## Publish with GitHub Pages
The GitHub account connected for this project is `abhaytiwari727534-svg`.

1. On GitHub, create a new public repository named exactly:
   `abhaytiwari727534-svg.github.io`
2. Keep it empty when creating it (do not add a README or license).
3. Open the new repository and choose **Add file → Upload files**.
4. Upload the *contents* of this folder (index.html, styles.css, script.js, README.md and the assets folder), not the outer ZIP.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. Your site address will be:
   `https://abhaytiwari727534-svg.github.io/`

## How to update the site later
- **Text:** open `index.html`, find the section, edit the text, and commit the change.
- **Colours, spacing and layout:** edit `styles.css`.
- **Small interactions:** edit `script.js`.
- **Project photos/videos:** put the new file inside `assets/`, then update the matching image or video path in `index.html`.
- Every commit to the published `main` branch triggers a new GitHub Pages deployment. Allow a short time for the update to appear.
